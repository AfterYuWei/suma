# 项目列表与服务分组

项目数量显示在标题右侧，筛选与搜索栏放在页头右侧，新建项目按钮放在搜索框下方并与其右侧对齐。项目列表按当前节点显示紧凑双行概览：项目身份及托管来源、服务数、实际存在容器的运行比例、已知异常与未知健康状态、CPU 和内存汇总。一次性容器参与项目总资源汇总，但不混入普通服务副本比例；配置中未创建的服务不会自动判为异常。

每行左侧依次为复选框、展开按钮和项目名称，展开按钮紧邻复选框右侧。点击项目行的空白、状态、来源或资源区域展开／收起服务；展开按钮支持键盘操作。点击项目名称或编辑入口进入项目编辑页（外部项目进入查看页）；复选框、启停与更多操作各自处理，不触发行展开。宽屏展开内容与项目名称对齐，窄屏保留自适应布局。

默认已知异常项目优先，同类按名称排序。可以搜索项目名、服务名或实际镜像，并组合运行状态、托管来源及异常筛选；所有筛选与排序作用于分页前的完整列表。搜索与筛选栏采用容器页的无底色行内布局，提供搜索清空及一键清除筛选；清除筛选保留排序。名称、CPU、内存支持切换顺序，未知资源值总是置后。偏好按节点保存，选中项目、打开操作菜单或 Dialog 时保持动态排序位置。

展开区与详情服务页共用横向服务列表，每个服务占满可用宽度。服务摘要统一显示名称、运行比例、健康、镜像及「CPU 合计／内存合计」；提示说明汇总口径，缺少采样时保留覆盖数。容器使用紧凑明细行，宽屏并排展示身份、指标、端口和操作菜单，窄屏自动换行；单容器复用服务层指标，明细只补名称、端口和操作，多容器按需展开各自的运行／健康与资源用量。去掉重复的指标背景块及底部计数，一次性容器另设列表分组。端口复用容器页的协议颜色标签与 `5432:5432` 格式，按容器查看，完整端口 Dialog 保留绑定 IP、IPv6 和协议。实际镜像引用或 Image ID 不同显示版本数量（包含同 tag 混用版本），仅有版本差异时在实例内补充具体镜像，悬浮可查看完整引用及 Image ID。点击容器名称进入完整详情；项目详情中的镜像状态可以打开明确的镜像更新详情 Dialog，保留检测结果、交付项目链接及原有更新审阅流程。健康摘要按需加载诊断，可以在诊断弹窗内选择副本。

容器操作菜单集中提供日志、文件和终端入口，在同一个容器 Dialog 内切换，不改变路由、列表位置和项目展开状态；关闭后焦点返回对应操作菜单按钮。点击容器名称仍进入完整详情。日志可读取已停止容器的保留输出，文件与终端需要容器运行。离开文件页签、关闭、切换容器、切换节点或离页时保护未保存文件；停止／删除容器后仍保留已加载的文件草稿。只挂载当前页签，关闭、切换与离页释放读取请求、日志和终端流。

列表提供托管项目编辑、启动（Compose up）／停止（stop），更多菜单包含重启、Down 和删除；外部项目保留查看、接管及清理能力。镜像检测、更新结果和更新操作仅在项目详情页处理，批量列表不提供更新入口。破坏性操作沿用现有确认、Task 和 Audit。

## 多副本预览示例

在当前节点新建 `nginx-preview` 项目，粘贴或导入 [nginx-replicas.compose.yml](examples/nginx-replicas.compose.yml)，校验后启动。示例声明一个 nginx 服务和两个副本；每个容器自动分配一个主机端口，绑定节点的 `127.0.0.1`，避免副本竞争固定端口。HTTP 健康检查成功后，服务卡片显示 `2/2 运行中`；展开可查看两个容器各自的端口、指标、日志／文件／终端入口。

可只读校验示例：

```bash
docker compose -p nginx-preview -f doc/examples/nginx-replicas.compose.yml config --quiet
```

## 数据与兼容

`GET /api/v1/nodes/:nodeID/projects` 的摘要新增可选 `declared_service_names`，成功读取时为空数组或排序后的服务名；外部项目及读取／解析失败时省略。列表明确提示托管声明不可用。容器列表及项目服务接口另提供可选 `image_id`，直接取自 Docker 的容器列表，用于区分同 tag 的实际镜像版本，不增加逐容器 Inspect。配置正文、环境值、源路径和配置镜像不进入项目摘要；原有 `service_count` 和 `instance_count` 保持 Docker 运行态计数语义。

列表一次查询节点容器，再按精确 Compose 项目／服务标签聚合；展开不再发项目服务或镜像更新请求。详情页仍按项目加载容器，两者共享节点元数据与指标缓存。元数据每 10 秒刷新、30 秒有效；指标每 5 秒刷新、15 秒有效。状态不匹配及重启前采样不用于当前判断。CPU 可超过 100%，真实零保持零；缺失字段不补零，部分采样显示覆盖数。

无需数据库迁移，不变更生产数据、应用文件或加密密钥。
