# 新增独立容器

在容器页搜索区域下方点击「新增容器」，或在命令面板中搜索「新增容器」。页面顶部显示目标节点。

基础配置填写容器名称和镜像，可从本地镜像候选项中选择，也可手动填写公开或私有镜像引用。默认仅在本节点缺少镜像时拉取；私有镜像使用认证中心中授权给该节点、且与镜像仓库匹配的凭据。勾选「创建后立即启动」时，会在创建完成后启动容器。

「网络与存储」配置网络、TCP／UDP 端口及具名卷／绑定挂载。端口默认绑定 `127.0.0.1`，宿主机端口 `0` 表示自动分配；需要外部访问时显式选择具体 IP 或 `0.0.0.0`。绑定挂载来源属于 Docker 节点，必须是非插值的绝对路径。不存在的具名卷由 Docker 创建。Docker socket 挂载沿用双重确认，只读挂载同样授予完整 Engine 控制能力。

「运行配置」配置环境变量、重启策略、运行用户、工作目录和 CPU／内存限制；环境变量值默认隐藏。高级配置可设置命令、入口参数、只读根文件系统、TTY 和标准输入。命令和入口每行一个参数，空白沿用镜像默认值。例如三行 `sh`、`-c`、`sleep 3600` 表示在容器内运行该命令。

提交后显示拉取／创建／启动进度，可打开任务详情或取消任务。创建成功后可查看容器，也可返回列表；列表会刷新并清除筛选，以便找到新容器。失败时保留表单配置供修改重试。若容器已创建而启动失败或被取消，容器和创建 ID 会保留，请先检查现有容器，再决定启动、修改名称重试或按正常删除流程清理。关闭页面不取消后台任务。

未提交的配置只存在于当前页面内存，离开页面或切换节点会要求确认丢弃；切换节点后不会将旧节点配置提交到新节点。服务重启不自动重放创建配置，任务中心会标记中断任务；应核对 Docker 中的实际资源再操作。
