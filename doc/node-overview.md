# 主页节点资源

主页使用紧凑节点资源列表。每行展示节点名称与连接状态、容器 CPU 占比、容器内存占比与容量，以及运行／暂停／停止容器数量。CPU 和内存摘要只显示精确数字；桌面按列对齐，手机将名称、指标和容器状态分行排列。列表随页面自然滚动，不设置内部滚动区域。

单节点与多节点初始全部收起。点击节点摘要，或聚焦摘要后按 Enter／Space，可独立展开或收起任意节点，同时展开多个节点可以对照趋势和容器排行。展开状态不跨页面保存；分组移除节点后，重新显示时保持收起。独立排序手柄支持拖动及方向键排序，并复用既有浏览器顺序偏好；分组内排序保留隐藏节点的偏好。排序与节点信息按钮不会触发展开。

展开、收起和排序的布局动画仅作用于节点列表内的位置变化，不缩放节点文字或图表。首页“节点资源”标题、说明、管理入口及持续交付区域不参与布局动画；系统偏好减少动态效果时，节点位移动画立即完成。

## 资源详情

展开区仅显示最近五分钟 CPU／内存趋势、内存 Top 5 与“全部容器”入口，不重复节点标题、大号用量或容器状态区。宽屏趋势并排，窄屏纵向排列。主机配置与磁盘统计收在节点信息抽屉，收起时也能从摘要的信息按钮直接打开。

- CPU 表示容器 CPU 百分比合计除以节点核数；内存表示容器内存合计占节点总内存的比例。它们不包含其他宿主进程的负载。
- 摘要数字和趋势沿用同一计算口径。65% 和 85% 分别使用警告和高负载文字颜色；超过 100% 时保留真实数值，趋势纵轴允许扩展。
- CPU 与内存分别绘制最近五分钟趋势，每十秒刷新，始终显示时间与百分比刻度。悬浮或点击图表显示响应收到时的观测时间及精确百分比，时间使用应用时区。
- 有效观测跨度不足一个十秒采样周期时，显示当前值参考线，并提示趋势正在积累；没有补造过去五分钟的历史。请求失败、不可用或超过三十秒的间隔形成断点，真实零值正常绘制。观测峰值只计算窗口内实际收到的有效观测。
- 摘要始终显示运行、暂停、停止数量。信息加载、离线或禁用时显示不可用标记，真实零值正常显示。
- 内存 Top 5 排除指标不可用的容器，按内存降序、名称、ID 稳定排序。横条以该节点榜首的内存量为参照，保留名称、容量及次级 CPU 数字；数据不完整时明确提示。
- 加载、失败、离线、禁用、无运行容器与没有可用指标分别呈现。各节点查询和重试独立，不会阻塞健康节点。

展开或收起不改变全局 Docker 操作节点。点击“全部容器”后，先等待目标节点切换和未保存草稿保护成功，再进入该节点的容器页面。

## 查询与历史

所有可见节点每十秒读取 info。收起节点使用现有 small 指标投影，每个展开节点使用 medium 投影；每行的一份查询结果供摘要与展开区共用。主页不请求 large 投影。收起节点会卸载图表、停止 medium 轮询并取消失去观察者的详情请求，恢复 small 投影；其他展开节点继续刷新。分组移除节点会取消该节点请求并关闭其展开区和信息抽屉。

最近五分钟历史保存在 TanStack Query 内存缓存中，按节点 ID、配置更新时间和 Agent 连接身份隔离。收起重开或短暂隐藏分组保留近期历史；连接身份变化和页面重新加载后重新积累。历史时间取浏览器收到指标响应的时间。

节点摘要的信息按钮打开只读抽屉，展示主机／Engine、连接信息、资源数量与 Docker 占用。网络／卷数量和 Docker 占用仅在抽屉打开且节点可用时查询，分别每十秒和六十秒刷新，各自独立重试。关闭抽屉或切换分组移除目标节点时，取消进行中的请求和轮询。Docker 占用没有主机磁盘总容量，因此不展示磁盘使用率。

## 验证

- `cd web && npm test`：比例计算、真实零值、超 100%、五分钟裁剪、断点、连接身份与 Top 5 排序。
- `cd web && npx playwright test -c playwright.overview.config.ts`：中英文、深浅主题及 320／390／1440px，默认收起与单节点低负载、多节点独立展开、长名称／长列表、加载／失败／离线／禁用／部分指标、分组移除、历史与初始参考线、拖动／键盘排序、展开键盘交互与控件隔离、触屏按钮布局、收起停止详情轮询、抽屉按需请求／取消和受保护的跨节点跳转。
- 完整 Web lint／typecheck／build、Go test／build，以及通用、容器和项目服务浏览器回归。
- `cd server && SUMA_RUN_DOCKER_SMOKE=1 go test -tags=dockersmoke ./internal/api -run '^TestRealDockerNodeOverviewReads$' -count=1 -v`：独立真实本地 Docker socket 只读 smoke，覆盖 info、各指标投影、资源数量及磁盘查询；仅使用隔离 PostgreSQL 测试 schema。

测试数据库通过根目录私有 `.env.local` 或进程环境中的 `SUMA_TEST_DATABASE_DSN` 配置。HTTP／数据库契约没有调整，生产数据库、文件和密钥没有更改。
